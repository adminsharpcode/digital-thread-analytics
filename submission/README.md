## Read this before submitting

The experiments were executed against a **specification replica** of the AI4I
2020 dataset, because the machine running them could not reach the UCI
repository. The replica reproduces the published marginal distributions, the
five documented failure mechanisms and the documented 3.39 % failure rate, but
it is not the original file.

To regenerate against the real dataset:

1. Download AI4I 2020 from <https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset>
2. Place `ai4i2020.csv` in `data/raw/`
3. Set `allow_synthetic_fallback: false` in `config/config.yaml`
4. Run `python run.py evaluate`
5. Update the figures in Section XVI of the manuscript

The framework records which source was used as an `origin` attribute on the
dataset node, so the distinction is visible in any provenance query and in the
dashboard. Section XII of the report discusses this as a demonstration of the
framework's own auditability claim.
